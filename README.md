# Luma для телефона

Android-приложение Luma (фильмы, сериалы, аниме) в той же оболочке, что и Luma TV: Kotlin + веб-интерфейс из `assets`, видео играет нативный ExoPlayer.

- Главная с баннером трендов TMDB и рядами, каталог с жанрами, ТВ-каналы с телепрограммой и каталогом мира, подборки Letterboxd/MDBList/Trakt, праздничные подборки, поиск (фильмы и люди), «Моё».
- Страница фильма: кадр и логотип TMDB, оценки (Кинопоиск, IMDb, TMDB, Letterboxd, Rotten Tomatoes, Metacritic), вкладки «О фильме», «Серии» с отметками «досмотрено», «Трейлеры», «Актёры» (страницы людей), «Кадры», «Похожее».
- Настройки: ключи сервисов, синхронизация с Luma на ПК и ТВ (по Wi-Fi, общий формат резервной копии), обновления из GitHub.
- Плеер на весь экран в ландшафте: тап — панель, двойной тап — ±10 с или пауза, свайп вбок — перемотка с кадрами-превью, свайп справа — громкость, слева — яркость. Озвучка, субтитры (свой рендер, три размера), качество до 1080p, скорость, серии.
- Сборка и установка на телефон: `tools/deploy.sh` (адрес: `PHONE=ip:порт`). Отладка страницы: `node tools/cdp.mjs "<js>"`.
- Разбор страницы плеера сайта (`assets/parse.js`) пока скопирован из Luma TV; позже вынесем в общий модуль.
